ติดตั้ง ESP32 Live Code

เฟิร์มแวร์ v1.0.0 · สำหรับ ESP32 Dev Module (ESP32-WROOM-32, แฟลช 4MB)
  1. เสียบบอร์ด ESP32 เข้าคอมด้วยสาย USB (ต้องเป็นสายที่ส่งข้อมูลได้ ไม่ใช่สายชาร์จอย่างเดียว)
  2. กดปุ่มด้านล่าง แล้วเลือกพอร์ตของบอร์ด (มักชื่อ CP210x, CH340 หรือ USB Serial)
  3. เลือก Install แล้วรอจนเสร็จ (ประมาณ 1 นาที)

เบราว์เซอร์นี้ติดตั้งไม่ได้ — ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ ต้องเปิดหน้านี้ผ่าน https:// หรือ http://localhost

หลังติดตั้งเสร็จ
  1. ใช้มือถือหรือคอมต่อ WiFi ชื่อ ESP32-LiveCode รหัส 12345678
  2. เปิดเว็บ http://192.168.4.1 แล้วเริ่มลากบล็อกได้เลย
  3. อยากให้บอร์ดต่อ WiFi บ้าน/ออฟฟิศ: ☰ เมนู → ตั้งค่า WiFi แล้วเปิด http://esp32.local
ต่อไม่ติด?
  1. ไม่เห็นพอร์ตในรายการ: ติดตั้งไดรเวอร์ USB (CP210x หรือ CH340) แล้วเสียบใหม่
  2. ขึ้นว่า "Failed to connect": กดปุ่ม BOOT บนบอร์ดค้างไว้ ตอนที่เริ่มติดตั้ง แล้วปล่อยเมื่อเริ่มเขียน
  3. ปิดโปรแกรมอื่นที่เปิดพอร์ตนี้อยู่ (เช่น Arduino IDE, Serial Monitor)

ถ้าเลือก "Erase device" โปรแกรมที่บันทึกไว้บนบอร์ดและค่า WiFi จะถูกลบ
